# PID-Drift
Code for analysis performed in Heiney et al., "Information theoretic measures of neural and behavioural coupling predict representational drift."

This study used previously published data. The original datasets can be found below.

Driscoll LN, Pettit NL, Minderer M, Chettih SN, Harvey CD. Dynamic Reorganization of Neuronal Activity Patterns in Parietal Cortex. Cell. 2017;170(5):986–999.e16. doi:10.1016/j.cell.2017.07.021.
Data repository: <https://datadryad.org/dataset/doi:10.5061/dryad.gqnk98sjq>

Marks TD, Goard MJ. Stimulus-Dependent Representational Drift in Primary Visual Cortex. Nature Communications. 2021;12(1):5169. doi:10.1038/s41467-021-25436-3.
Data repository: <https://datadryad.org/dataset/doi:10.25349/D9M606>

Partial information decomposition (PID) was performed using the IDTxL toolbox, available at <https://github.com/pwollstadt/IDTxl>.
